A [make.fun](https://make.fun/bounty/u-kreutzx-the-one-line-exit-1dc652d1) entry for **The One-Line Exit** — the funniest single-line resignation letter wins.

## The entry

> I resign, effective immediately: the penguins have unionized, and frankly, they have a point.

(93 characters — inside the kit's 1–140 character gate.)

A zookeeper quits over a labour dispute he cannot win: the other side
has the moral high ground, and also flippers.

## How it works

`main.py` writes the line above to `/output/entry.txt` (or to the file
path in `$ENTRY_OUT` when set), with no trailing newline, and verifies
the file holds exactly that line. Run it with:

```sh
python3 main.py
```
